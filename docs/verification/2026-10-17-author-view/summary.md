# 博主视图 preview 验收（2026-10-17）

preview 夹具（`tools/preview_fixture.py`，演示数据）+ 浏览器实测，桌面端。

## 验收项

| 场景 | 预期 | 结果 |
|---|---|---|
| 卡片点头像 | URL 变 `?author=<key>`、头部条出现（头像/昵称/统计/外链/退出）、墙只剩该博主、状态归「全部」、漏斗徽章归零 | ✓ |
| 头部统计 | `113 帖 · 注 2 · 2026-10`（演示数据；保留/收藏为 0 不显示），微博外链拼 `weibo.com/u/<uid>` | ✓ |
| 快照退出 | 先搜「山间」→ 点头像（搜索框清空、URL 带 author）→ ✕ 退出：搜索词与 URL 整组还原、头部条隐藏 | ✓ |
| 详情入口 | 详情头像同款按钮，点击关详情并进博主视图（回看态同路径） | ✓ |
| 编年态互让 | 编年布局下博主条 sticky，日卷粘滞头/尺子的 `--tl-top` 顶到博主条下方（115=115），退出回位（55） | ✓ |
| 胶囊联动 | 作者胶囊筛选时博主条同样出现（同一视图模型）；再点胶囊取消即隐藏 | ✓ |
| 直开 URL | `/?author=…` 无快照，退出回默认全部视图 | ✓ |
| 多选模式 | 点头像 = 勾选，不进博主视图 | ✓ |
